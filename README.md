# Story-Detect-Emotion 📖🎭

A web-based platform designed to automatically detect and analyze emotions from user-submitted stories or text directly within the browser.

## ✨ Key Features
* **Automated Emotion Detection:** Analyzes story text to seamlessly classify different emotional states (such as Happy, Sad, Angry, Fearful, Surprised, etc.).
* **Pure Web-Based Experience:** Runs entirely inside the web browser without requiring any local software installation or complex environment setup.
* **Interactive UI:** Provides a clean, intuitive, and responsive interface for users to input narratives and view emotional analysis instantly.

## 🚀 Getting Started

### Prerequisites
Since this is a client-side web project, you only need a modern web browser (such as Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).

### Installation & Running Locally

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   ```
2. **Launch the Web Page:**
   * Navigate to the cloned project directory.
   * Locate the file named `Rasa - Deteksi Emosi dari Tulisanmu.html`.
   * Double-click the file to open and run it directly in your preferred web browser.
